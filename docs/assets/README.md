# Documentation assets

`house-model-comparison.png` and `blue-jay-model-comparison.png` were generated by `scripts/build_readme_comparison.py`. `image-track-baselines.png` was generated by `scripts/build_image_track_gallery.py`. All use fresh MimesisGym evaluation results recorded on 2026-08-28.

- GPT-5.4 ran through OpenAI Responses with low reasoning. It submitted in five turns with visual v2 reward 0.7531170646 and adjusted reward 0.7282170646.
- GPT-5.6 Luna ran through OpenAI Responses with low reasoning. It submitted in five turns with visual v2 reward 0.9030451288 and adjusted reward 0.8809451288.
- On the four natural images, both models submitted every task using independent contexts, offline 2 GB containers, native source dimensions, and identical limits. GPT-5.4 averaged 0.3668632170 match and 0.2437682170 final; GPT-5.6 Luna averaged 0.4091600945 match and 0.3791300945 final.
- The blue jay is public domain, credited to Mike Carlo/USFWS. Artists Palette is CC0. The coral reef is public-domain NOAA imagery, and the monarch butterfly is public-domain USFWS imagery.

The author-drawn house and generated comparison assets are included under the repository's Apache-2.0 license; source-image rights remain as stated above. Raw API traces, credentials, and ignored run directories are not part of the public documentation.
